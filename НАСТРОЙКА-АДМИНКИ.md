# Настройка админки

Это делается один раз. Бесплатного тарифа Supabase достаточно.

1. Создайте проект на https://supabase.com/dashboard.
2. Откройте **Authentication → Users → Add user → Create new user**. Укажите email отца и придумайте ему пароль. Галочку подтверждения email можно включить сразу.
3. Откройте файл `supabase-setup.sql`, замените `EMAIL_ОТЦА` на созданный email (он должен остаться в одинарных кавычках).
4. В Supabase откройте **SQL Editor → New query**, вставьте изменённый SQL и нажмите **Run**.
5. Откройте **Project Settings → API**. Скопируйте **Project URL** и публичный ключ **anon / publishable**.
6. Вставьте их в `supabase-config.js`:

```js
window.TTS_SUPABASE = {
    url: "https://ваш-проект.supabase.co",
    anonKey: "ваш-публичный-ключ"
};
```

7. Загрузите на хостинг новые файлы вместе с сайтом.
8. Откройте `https://адрес-сайта/admin.html`, войдите и нажмите **Сохранить цены**. При первом сохранении админка сама перенесёт текущий прайс из сайта в базу.

Пароль нельзя записывать в файлы сайта или отправлять кому-либо. `Project URL` и `anon / publishable key` являются публичными параметрами; безопасность изменения цен обеспечивают правила доступа из SQL.
